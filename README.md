# We Win – AI-Powered Government Exam & Aptitude Platform 🏆

A modern, responsive, production-grade AI mock test platform designed for competitive **Government Exams** (SSC, Banking, Railways, UPSC, MPSC & State Exams) and **Aptitude Tests**.

- **GitHub Repository**: [https://github.com/Prashantpowar45/we-win-ai-exam](https://github.com/Prashantpowar45/we-win-ai-exam)
- **Developer**: Prashant Powar ([@Prashantpowar45](https://github.com/Prashantpowar45))

---

## ✨ Key Features

1. **Student Dashboard & Analytics**:
   - Practice streaks, XP points, level progression.
   - Overall accuracy %, average score, and national rank.
   - Weak vs Strong topic analysis with AI focus alerts.
   - Adaptive AI recommended test suggestions.

2. **Comprehensive Exam Categories**:
   - **Government Exams**: SSC (CGL, CHSL, MTS, GD, CPO), Banking (IBPS PO/Clerk, SBI PO/Clerk, RBI), Railways (RRB NTPC, ALP), UPSC (CSAT, Prelims), State Exams (MPSC, Police Bharti, Talathi, ZP, Gram Sevak).
   - **Aptitude Tracks**: Quantitative Aptitude, Logical Reasoning, Verbal Ability, Data Interpretation, Coding Aptitude.
   - **General Knowledge (2020-2026)**: Indian Constitution, Budget, ISRO & Space Missions, Defense, Maharashtra GK.

3. **Professional Exam Engine Simulator**:
   - Countdown Timer & Emergency Auto-Submit.
   - Interactive Question Palette (Answered, Unanswered, Marked for Review, Not Visited).
   - Controls: Save & Next, Mark for Review, Clear Response, Previous, Fullscreen Mode.
   - Formulas Sheet drawer & Question Bookmarking.

4. **AI Features**:
   - **AI Step-by-Step Solutions**: Multi-language explanations after test completion.
   - **AI Mistake Diagnosis**: Identifies conceptual gaps vs speed rushes.
   - **We Win AI Tutor**: Floating interactive AI assistant supporting English, Hindi (हिंदी), and Marathi (मराठी).

5. **Gamification & Leaderboards**:
   - Global, State (Maharashtra), and College Rankings.
   - Unlockable Badges (*First Test Passed*, *7-Day Streak*, *Accuracy King*, *GK Specialist*).

6. **Admin Panel**:
   - Question bank management, mock test creator, and CSV bulk question import simulation.

7. **Multi-Language Support**:
   - Instant language switching between English, Hindi, and Marathi across questions and UI.

## 🚀 Setup & Run Instructions

```bash
# Clone the repository
git clone https://github.com/Prashantpowar45/we-win-ai-exam.git
cd we-win-ai-exam

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
npm run start
```
